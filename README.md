# Antigravity & Agent Skills

Collection of skills for Antigravity, Claude Code, Cursor, Codex, and other AI coding agents.

### Installation & Directory Paths
- **Antigravity 2.0:** `~/.gemini/config/skills`
- **Antigravity (Legacy):** `~/.gemini/antigravity/skills`
- **Global Agents:** `~/.agents/skills`

---

## Skills Catalog

### Development & Engineering Workflow
- **`code-review`**: Code review along standards and spec.
- **`codebase-design`**: Shared vocabulary for designing deep modules.
- **`diagnosing-bugs`**: Systematic diagnosis loop for hard bugs and performance regressions.
- **`domain-modeling`**: Build and sharpen project domain models.
- **`implement` / `implement-spec`**: High-precision feature implementation from specs.
- **`improve-codebase-architecture`**: Deep architecture refactoring and decoupling.
- **`resolving-merge-conflicts`**: Conflict resolution assistant.
- **`tdd` / `test-driven-development`**: Test-driven development workflows.
- **`python-testing-patterns`**: Testing strategies with pytest, fixtures, and mocking.
- **`python-code-style`**: Python conventions, linting, and formatting standards.
- **`java-coding-standards`**: Spring Boot & Quarkus coding standards.
- **`java-junit`**: JUnit 5 unit testing and data-driven test patterns.
- **`javafx-modern-ui`**: Modern JavaFX UI/UX designer.
- **`javafx-precison-coding`**: Production-grade JavaFX development without hardcoded values.

### Execution & Superpowers
- **`using-superpowers`**: Disciplined skill-first agent execution workflow.
- **`brainstorming`**: Collaborative requirement exploration before implementation.
- **`executing-plans`**: Step-by-step implementation plan execution with checkpoints.
- **`writing-plans`**: Structural planning for multi-step tasks.
- **`writing-skills`**: Authoring, modifying, and testing agent skills.
- **`subagent-driven-development`**: Multi-agent task execution.
- **`verification-before-completion`**: Mandatory verification and evidence before completion.
- **`superpowers-ponytail`**: Disciplined process combined with minimalist, lazy execution.
- **`stress-tested-architecture`**: Architecture design coupled with adversarial grilling.
- **`precision-diagnostics`**: Multi-phase root-cause diagnosis.

### Efficiency & Formatting
- **`caveman` / `caveman-th` / `caveman-coding` / `caveman-plan`**: Token-efficient ultra-terse response and execution modes.
- **`ponytail` suite (`ponytail`, `ponytail-review`, `ponytail-audit`, `ponytail-debt`, `ponytail-gain`, `ponytail-help`)**: Ruthless simplicity and YAGNI principle enforcement.
- **`humanizer` / `humanizer-th`**: Natural prose re-writing without AI stylistic tells.

### Productivity & Tools
- **`find-skills`**: Skill discovery and installation manager.
- **`skill-creator`**: Benchmark, eval, and package agent skills.
- **`deep-study`**: Folder structure analysis and tree workflow generation.
- **`full-system-audit`**: High-level and detailed project audit.
- **`flowchart-designer`**: System flowchart design.
- **`frontend-slides`**: HTML/CSS web presentation decks.
- **`pptx-generator` / `elite-powerpoint-designer`**: PowerPoint generation and formatting.
- **`office-mcp`**: Microsoft Office MCP tools integration.
- **`omp-add-provider`**: Oh My Pi model provider configuration.
