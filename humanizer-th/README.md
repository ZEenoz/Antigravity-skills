# Humanizer (ไทย)

ทำให้ข้อความภาษาไทยที่ดูเหมือน AI เขียน อ่านเหมือนคนเขียน โดย**ไม่เปลี่ยนสาระ** และ**ไม่แต่งข้อมูลที่ไม่มีในต้นฉบับ**

เป็นเวอร์ชันภาษาไทยของสกิล Humanizer ที่มีรูปแบบการเขียน 26 ข้อจาก ["Signs of AI writing"](https://en.wikipedia.org/wiki/Wikipedia:Signs_of_AI_writing) ของวิกิพีเดีย และเพิ่มอีก 10 ข้อที่เฉพาะภาษาไทย รวมถึงคู่มือว่าเอกสารแต่ละแบบควรเขียนอย่างไร และกฎอักขรวิธีภาษาไทย

**ก่อน:**
> ในยุคปัจจุบันโลกมีการเปลี่ยนแปลงเกิดขึ้นอย่างรวดเร็ว อุตสาหกรรมการผลิตชิปก็ไม่ยกเว้น
>
> ชิปวัดผลการผลิตใหม่ คือกุญแจสำคัญที่จะเปลี่ยนแปลงวิธีการตรวจสอบคุณภาพของคุณ มันไม่ใช่แค่เครื่องมือวัดผลการผลิตธรรมดา แต่เป็นสู่พรรภิยมใหม่
>
> โดยสรุปแล้ว ชิปวัดผลการผลิตใหม่นี้เป็นกุญแจสำคัญที่จะช่วยยกระดับการตรวจสอบคุณภาพของคุณไปสู่อีกระดับหนึ่ง หากต้องการให้ช่วยเพิ่มเติม ติดต่อทีมงานได้เลยครับ

**หลัง:**
> อุตสาหกรรมการผลิตชิปต้องการความแม่นยำสูงขึ้นเรื่อยๆ เพื่อให้ตอบโจทย์ลูกค้าได้ครบ
>
> ชิปวัดผลการผลิตใหม่เปลี่ยนวิธีตรวจสอบคุณภาพ โดยวัดค่าความแม่นยำ ตรวจสอบความสม่ำเสมอ และวิเคราะห์ข้อมูลเชิงลึก ประมวลผลได้เร็วกว่ารุ่นก่อน 30% ใช้งานร่วมกับเครื่องจักรเดิมได้ทันที และรองรับการเข้ารหัสข้อมูลตามมาตรฐานสากล

## สิ่งที่ต่างจากเวอร์ชันอังกฤษ

รูปแบบที่ต้องจับ 26 ข้อแรกเหมือนต้นฉบับ แต่ตัวอย่าง คำที่เฝ้าระวัง และเหตุผลเขียนใหม่ทั้งหมดให้เข้ากับภาษาไทย ส่วนที่เพิ่มใหม่คือ

| # | รูปแบบ | ตัวอย่าง |
|---|---|---|
| 28 | ใช้ "ถูก/โดน" กับเรื่องที่ไม่ได้แย่ | โครงการนี้ถูกดำเนินการโดยทีมวิจัย → ทีมวิจัยดำเนินโครงการนี้ |
| 29 | "ทำการ" และการซ้อน "การ + กริยา" | มีการดำเนินการในการส่งเสริมการพัฒนา... → บริษัทส่งเสริมให้... |
| 30 | สรรพนามที่ไม่จำเป็น | มันช่วยให้เราประหยัดเวลา → ช่วยประหยัดเวลา |
| 31 | คำเชื่อมทางการที่ขึ้นต้นทุกประโยค | อย่างไรก็ตาม ในขณะเดียวกัน การเปลี่ยนแปลง... → การเปลี่ยนแปลงนี้... |
| 32 | เว้นวรรคผิดในภาษาไทย | การ ทำงาน ของ ทีม → การทำงานของทีม |
| 33 | ๆ ๏ และ ฯ ผิดตำแหน่งหรือผิดชนิด | เด็กเล็กๆ → เด็กเล็ก ๆ · คณะฯ → คณะกรรมการ |
| 34 | ศัพท์อังกฤษและคำแปลตรงตัว | ในตอนท้ายของวัน → สุดท้ายแล้ว |
| 35 | หัวข้อที่ไม่บอกเนื้อหา | ## ภาพรวม → ## สถานะการใช้งานและปัญหาที่พบ |
| 36 | ข้อความที่ไร้ความเป็นคน | ไม่มีความเห็น ไม่มีสำนวน ไม่มีตัวเลข → ยังไร้ความเป็นคน |
| 27 | ครับ/ค่ะ และระดับภาษาที่ปนกัน | ทุกประโยคลงท้าย "ค่ะ" → เลือกตามผู้เขียนและระดับเดียวตลอดเอกสาร |

หลักฐานที่ใช้ประกอบมาจากงานวิจัยภาษาไทย เช่น งานวิเคราะห์ข้อความ AI 300 ชิ้นของมหาวิทยาลัยมหามกุฎราชวิทยาลัย ซึ่งวัดว่าโมเดลใช้ประโยค "ถูก + กริยา" ในบริบทบวกถึง 74% ในผลงานสรุปโครงการ และงานเปรียบเทียบงานเขียนของ ChatGPT กับงานนักเรียนไทยของมหาวิทยาลัยราชภัฏเชียงใหม่

## การใช้งาน

เรียกสกิลโดยตรง

```
/humanizer-th

[วางข้อความภาษาไทยที่ต้องการแก้]
```

หรือบอกเป็นภาษาธรรมดา

```
ช่วยทำให้ข้อความนี้เป็นธรรมชาติหน่อย ไม่ต้องเปลี่ยนสาระ
```

### เลือกระดับภาษาให้ตรงกับผู้อ่าน

ถ้าบอกชนิดเอกสาร สกิลจะใช้คู่มือใน `references/doc-types.md` ที่ตรงกับชนิดนั้น เช่น

```
นี่คืออีเมลที่จะส่งให้ลูกค้า แก้ให้สุภาพแต่ตรงประเด็น
```

ถ้าต้องการเสียงของตัวเอง ให้ใส่ตัวอย่างงานเขียนมา สกิลจะเลียนแบบความยาวประโยค การเลือกคำ และเครื่องหมายวรรคตอนให้

```
นี่คือตัวอย่างงานเขียนของผม 3 ย่อหน้า
[วางตัวอย่าง]

แล้วนี้คือข้อความที่ต้องแก้
[วางข้อความ]
```

## เอกสาร 13 แบบที่มีคู่มือ

หนังสือราชการ · อีเมลธุรกิจ · รายงาน · รายงานวิจัย วิทยานิพนธ์ และรายงานสหกิจศึกษา · ข่าวและข่าวประชาสัมพันธ์ · บทความ บล็อก และคอลัมน์ · โพสต์โซเชียลและแคปชัน · คำโปรยโฆษณา · สัญญาและเอกสารทางกฎหมาย · คู่มือและ SOP · ประกาศรับสมัครงาน · สไลด์นำเสนอและสรุปผลประชุม · ข้อความลูกค้าและข้อความขออภัย

```bash
npx skills add <path-or-repo> --global --agent '*'
```

## ขอบเขต

- เป้าหมายคือให้ผู้อ่านอ่านสบายขึ้น ไม่ใช่หลบเครื่องมือตรวจจับ AI งานเขียนก่อน 30 พฤศจิกายน 2565 ไม่ใช่งานเขียนด้วย AI
- สกิลจะไม่เพิ่มข้อมูล ชื่อ ตัวเลข วันที่ คำพูด หรือการอ้างอิงที่ไม่มีในต้นฉบับ ถ้าข้อความต้องการรายละเอียดที่ไม่มี สกิลจะถาม
- ถ้าหน่วยงานของคุณมีคู่มือภาษาไทยของตัวเอง ให้ยึดคู่มือนั้น คู่มือภายในสามารถต่างจากค่าเริ่มต้นทั่วไปได้

## สิ่งหนึ่งที่ควรรู้ก่อนใช้

หลักเกณฑ์ภาษาไทยบางฉบับขัดกันเอง เรื่องที่พบบ่อยที่สุดคือจุดจบประโยค หลักเกณฑ์ของสำนักงานราชบัณฑิตยสภาอนุญาตให้ใช้ "." จบประโยคไทยได้ แต่คู่มือมาตรฐานการเขียนสื่อสิ่งพิมพ์ (สสวท. 2564) ระบุว่าไม่ควรใช้ และวิกิพีเดียไม่ใช้เช่นกัน สกิลนี้เลือกตามคู่มือสื่อสิ่งพิมพ์ คือจบประโยคไทยด้วยช่องว่าง ไม่ใช่ด้วย "." รายละเอียดทุกข้อที่แหล่งอ้างอิงขัดแย้งกันอยู่ใน `references/typography.md`
